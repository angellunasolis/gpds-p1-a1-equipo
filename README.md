# Sitio Web - Podólogo Arbey Valdivia

Sitio web institucional del Podólogo Arbey Valdivia, conocido como el **Podólogo de las estrellas** en Monterrey, NL. Desarrollado como proyecto académico con fines informativos y de contacto para pacientes.

## 🌐 Demo en vivo

> Próximamente en Netlify

## 📋 Descripción

Landing page informativa con las siguientes secciones:

- **Inicio** — Hero, estadísticas, testimonios de pacientes y servicios destacados
- **Servicios** — Catálogo completo de tratamientos con layout alternado e integración a WhatsApp
- **Sobre mí** — Historia, experiencia del podólogo y clientes destacados con modal
- **Galería** — Slider interactivo de comparación antes y después
- **Contacto** — Ubicación, mapa, horario de atención y redes sociales
- **404** — Página de error personalizada

## 🛠️ Tecnologías utilizadas

- HTML5
- CSS3 (Variables CSS, Flexbox, Grid, animaciones, clamp())
- JavaScript Vanilla (IntersectionObserver, modales, slider interactivo)

## ✨ Características

- Diseño responsivo (móvil, tablet y escritorio)
- Menú hamburguesa tipo drawer lateral con overlay
- Active state en navegación por página activa
- Slider de comparación antes/después en galería
- Modal de clientes destacados
- Animación de estadísticas con contador
- Botón scroll to top con ícono local SVG
- Botón flotante de WhatsApp con mensajes preescritos por servicio
- Imágenes optimizadas en formato WebP
- Página 404 personalizada
- Meta descriptions y favicon en todas las páginas

1. Clona el repositorio

No requiere instalación de dependencias ni servidor.
